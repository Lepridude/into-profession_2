## Установка и запуск

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Создать файл `.env` в корне репозитория:

```dotenv
GIGA_KEY=ваш_api_ключ
```

Открыть `llm_work.ipynb` в Jupyter Notebook или VS Code с расширениями Python и Jupyter, выбрать Python kernel и выполнять ячейки сверху вниз.

Файл `.env` содержит секрет и не должен добавляться в Git. Для работы в Codespaces секрет должен быть доступен среде выполнения как переменная окружения `GIGA_KEY`.
