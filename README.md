## Запуск

Требуется Python 3.11 или новее.

1. Установить зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Создать локальный файл `.env` в корне проекта и указать в нём свой ключ:

   ```dotenv
   GIGA_KEY=ваш_api_ключ
   ```

3. Открыть `llm_work.ipynb` в Jupyter Notebook или VS Code с расширениями Python и Jupyter.
4. Выбрать Python kernel и выполнять ячейки по порядку.

Не публикуйте файл `.env` и не вставляйте секреты API в исходный код или Git.
