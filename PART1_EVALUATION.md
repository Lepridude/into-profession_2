# Часть 1 — оценка точности (ветка llm-improve-1)

Для 15 заявок варианта 01 ноутбук запускает два варианта извлечения количества проживающих: базовый `PromptTemplate` и Few-shot через `ChatPromptTemplate`.

Для каждого подхода:
1. Ответы модели сохраняются в отдельный столбец.
2. Строковые ответы преобразуются в числа через `pandas.to_numeric(..., errors="coerce")`.
3. Значения сравниваются с эталонным `amount`.
4. Рассчитываются число верных ответов, число ошибок и точность:

`accuracy = correct / total`

Численные результаты намеренно не заполнены до выполнения запросов к GigaChat с действующим ключом. После запуска они выводятся в ноутбуке.
