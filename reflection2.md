# Рефлексия по практическому занятию 2

**Тема:** Работа с LLM через API  
**Студент:** Архангельский Данила Андреевич  
**Группа:** ИСТ-05  
**Вариант:** 01 — `rental_01.csv`

В практической работе подготовлена обработка 15 заявок на аренду жилья с помощью GigaChat через LangChain. В первой части реализованы базовый промпт на основе `PromptTemplate` и Few-shot-подход на основе `ChatPromptTemplate`. Качество обоих подходов оценивается сравнением предсказанного количества проживающих с эталонным столбцом `amount`. Для каждого подхода рассчитываются количество правильных ответов, количество ошибок и точность по формуле `accuracy = correct / 15 × 100%`. Фактические значения точности базового промпта и Few-shot пока не получены, поскольку в проверенной версии ноутбука отсутствуют результаты выполненных запросов к API. Поэтому утверждать, какой из двух подходов оказался точнее, пока нельзя. Во второй части используется Pydantic-модель для извлечения количества взрослых и детей, даты заезда, продолжительности проживания, цены за сутки и дополнительных пожеланий. Формат ответа модели ограничивается JSON-парсером, после чего результаты сравниваются с ручной разметкой из `gold_fields_01.csv`. Для пяти структурированных полей рассчитывается отдельная точность, а затем среднее арифметическое этих показателей. Численные значения точности полей и общей средней метрики также пока не рассчитаны, так как фактические ответы модели ещё не сохранены. После запуска API необходимо дополнить эту рефлексию полученными значениями и разобрать конкретную ошибку из таблицы результатов; без выходных данных модели достоверно назвать пример ошибки и её причину невозможно.
