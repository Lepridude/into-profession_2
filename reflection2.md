# Рефлексия по практическому занятию 2

**Тема:** Работа с LLM через API  
**Студент:** Архангельский Данила Андреевич

**Вариант:** rental_01.csv

В работе подготовлен вызов GigaChat из Python через LangChain. Для первой части реализованы базовый PromptTemplate и Few-shot-подход. Результаты обоих подходов сравниваются с эталонным столбцом amount на 15 заявках.

Для второй части определена Pydantic-модель с полями count_adults, count_children, start_date, nights, price_per_day и remarks. JsonOutputParser задаёт требуемый формат JSON, а Pydantic проверяет структуру и типы результата. Подготовлена ручная разметка gold_fields_01.csv, с которой сравниваются пять оцениваемых полей.

Фактические численные метрики и пример ошибки пока не указаны, поскольку запросы к GigaChat ещё не запускались. Их необходимо добавить после выполнения ноутбука. Результаты не подменяются предполагаемыми значениями.
