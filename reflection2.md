# Рефлексия по практическому занятию 2

**Тема:** Работа с LLM через API  
**Студент:** Архангельский Данила Андреевич  
**Группа:** ИСТ-05  
**Вариант:** rental_01.csv

В работе используется GigaChat из Python через LangChain. Для первой части подготовлены базовый PromptTemplate и Few-shot-подход. Ответы модели сравниваются с эталонным столбцом amount на 15 заявках.

Для второй части определена Pydantic-модель с полями count_adults, count_children, start_date, nights, price_per_day и remarks. JSON-парсер задаёт формат ответа, а Pydantic проверяет структуру и типы. Для оценки подготовлена ручная разметка gold_fields_01.csv.

Фактические метрики и пример ошибки следует внести после выполнения запросов к API. Числовые результаты не подменяются предположениями.
