# Рефлексия

**Архангельский Данила Андреевич, ИСТ-05, вариант 01**

В этой работе я разбирал заявки на аренду жилья с помощью GigaChat и LangChain. Для первой части сделал два варианта запроса: обычный промпт и Few-shot с примерами. В обоих случаях модель должна определить, сколько человек будет жить в квартире, не считая животных. Ответы сравниваются с числом из столбца `amount` в исходном файле. Ноутбук считает правильные ответы, ошибки и точность отдельно для каждого варианта. Пока я не получил сохранённые результаты запуска API, поэтому точные значения метрик здесь не указываю. Из-за этого пока нельзя сказать, какой промпт сработал лучше. Во второй части я добавил извлечение числа взрослых и детей, даты заезда, количества ночей, цены за сутки и дополнительных пожеланий. Для ответа используется JSON, а Pydantic проверяет, что полученные данные соответствуют заданной структуре. Затем результаты сравниваются с моей разметкой в `gold_fields_01.csv`, по каждому из пяти полей считается точность и выводится среднее значение. После запуска останется перенести сюда метрики и разобрать одну реальную ошибку модели из таблицы результатов.
